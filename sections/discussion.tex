\section{Discussion}\label{sec:discussion}

This section contains a discussion of the results of the evaluation in \refsec{sec:evaluation}.
It also introduces some possible further directions of the Pastèque development.

\subsection{Evaluation Results}\label{sec:evaluation-results}
The evaluation has shown that, for smaller instances, Pastèque with the LLVM backend is faster and uses less memory compared to the Standard ML backend.
For the large 512-bit multipliers however, the LLVM backend does not scale as well as it is slower and uses more memory than the Standard ML version.
